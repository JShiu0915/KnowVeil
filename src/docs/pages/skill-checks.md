## 三道检查 {#checks}

每一份送审都经过格式、质量、安全三道检查，一次完成，列出问题清单。三项结果分开列出。

检查只读取送审的内容，不会在你的环境里运行它。检查在企业自己的机器上进行，不连外网也能完成。

## 三种结论 {#verdicts}

| 结论 | 意味着什么 |
| --- | --- |
| 通过 | 出现在公开检索中，同事可以按版本安装 |
| 需复核 | 出现在检索结果中，带着需复核的标记 |
| 拒绝 | 不出现在公开检索中。问题清单已经列出，处理后可以重新提交 |

## 结论留档 {#records}

每一次检查的问题清单和结论都会保留，之后随时可以回看。
